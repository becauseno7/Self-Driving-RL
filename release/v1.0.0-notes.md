# Self-Driving RL v1.0.0

Self-Driving RL v1.0 freezes the project's first recommended layered driver
and packages its evidence for GitHub and Hugging Face review.

## Highlights

- A validation-selected V5 QR-DQN checkpoint from the 2.5M-step hard-mode run.
- A calibrated V6 RLAIF residual that makes sparse calm/pass corrections while
  keeping V5 frozen behind confidence and safety gates.
- V7/V8 deterministic control for persistent passing intent, dynamic traffic,
  proportional comfort braking, emergency braking, and clear-road recovery.
- A 33-value observation and 9-action joint steering/pedal interface.
- A browser-accessible deterministic replay, clearly separated from live model
  inference. The Pages URL remains a deployment placeholder until approval.
- Python 3.11/3.12 packaging, CPU CI, contribution guidance, security guidance,
  citation metadata, a Hugging Face model card, and a hash-verifiable manifest.

## Final held-out evaluation

On 100 previously unused hard/dynamic routes, seeds 690000–690099, each 45
seconds long, the recommended stack recorded:

| Metric | Result |
|---|---:|
| Completion | **100%** |
| Crash rate | **0%** |
| Mean net passes / route | **8.43** |
| Passing response | **90.2%** |
| Clear-road deep slowdown | **0.04% of steps** |

Raw evidence is packaged at
`release/huggingface/evaluation/v8-braking-final-unseen-100.json`.

## DAgger decision

Human DAgger teaching was a useful experiment, but no learned DAgger residual
was promoted. The final candidate preserved completion and crashes but failed
the net-passing non-regression gate; earlier candidates also regressed lane and
braking quality. The recommended driver loads no DAgger model.

## Compatibility and migration

- Python 3.11 or 3.12 is required.
- Current checkpoints require exactly 33 observations and 9 actions; older
  V1–V3 checkpoints are shape-incompatible.
- `sdr-game watch` loads only a plain game model. Use `sdr-rlaif watch` with
  both artifacts, `--longitudinal-intent`, and `--dynamic-traffic` for the
  recommended v1.0 stack.
- The `uv` source selects a CUDA 12.6 PyTorch wheel for the original workstation.
  Standard `pip install -e .` uses the platform-native PyPI wheel for CPU CI and
  cross-platform installation.

## Limitations

This is a structured-state simulator demonstration, not a perception stack or
real-vehicle controller. The measured seed range, authored traffic, and
45-second routes do not establish performance outside Neon Highway. The
Stable-Baselines3 model archive must be treated as trusted because its format
can deserialize cloudpickle.
